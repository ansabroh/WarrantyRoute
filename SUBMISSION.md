# Intelligent Contracts submission

Title: WarrantyRoute — Evidence-backed warranty eligibility

Description:
WarrantyRoute is a standalone GenLayer Intelligent Contract for product warranty eligibility. Immutable issuer registrations bind purchase records, original terms, claimant and authorized service accounts. Service attestations bind exact evidence to each claim. Independent validators retrieve commit-pinned SHA-256 evidence, reassess each defect and exclusion, compare decision fields and audit contextual quotation grounding. Deterministic code checks coverage/reporting dates and derives COVERED, PARTIALLY_COVERED, EXCLUDED or INCONCLUSIVE. Bounded retries and append-only hash-linked receipts preserve assessment history. No refunds or replacements are automatically approved. See EVIDENCE.md for verified tests and deployment status.
